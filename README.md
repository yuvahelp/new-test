# Yuva Help Android App

Modern Android app for **https://yuva.help/** that auto-syncs WordPress posts (jobs, results, admit cards, government schemes, and education news) using the WordPress REST API.

## Highlights

- Auto-fetches posts from `wp-json/wp/v2/posts?_embed=1`
- Clean Material 3 UI with card-based feed
- Sections on home screen:
  - Latest Jobs
  - Results
  - Admit Cards
  - Government Schemes
  - Education News
- Article reader screen with featured image, metadata, and full content
- Bottom navigation: Home, Categories, Latest, Search, About
- Search and share support
- Open original website links
- Offline cache using Room database
- Periodic background sync with notifications for updates

## Tech

- Kotlin + Jetpack Compose
- Retrofit + Gson
- Room
- WorkManager

## Run

1. Open in Android Studio Hedgehog+.
2. Let Gradle sync.
3. Run on emulator/device (API 24+).

## Notes

- Category mapping is auto-inferred from title/excerpt keywords and can be upgraded to real WordPress categories later.
- Notifications are generated by background sync worker when new data is fetched.
